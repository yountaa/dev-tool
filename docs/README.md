# Документация dev-tool

Источник правды по устройству проекта. Хранится в репозитории вместе с кодом.

Разработка ведётся параллельно несколькими участниками, поэтому договорённости
зафиксированы в документах. **Изменение поведения требует обновления
соответствующего документа в этой папке.**

## Состав

| Файл | О чём | Когда читать |
| --- | --- | --- |
| [AGENTS.md](AGENTS.md) | Правила работы над проектом: стиль, границы, чек-лист перед сдачей | **Первым делом, всегда** |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Полная схема: сервисы, модули, потоки данных, состояние в URL | Чтобы понять, что где лежит |
| [MODULES.md](MODULES.md) | Как добавить новый модуль (вкладку) от начала до конца | Задача «сделай новую вкладку» |
| [UI.md](UI.md) | Шрифты, палитра, компоненты, поведение интерфейса | Любая правка фронта |
| [VICTORIA.md](VICTORIA.md) | Модуль victoria: кластеры, график, тултип, скорость | Работа с метриками |
| [RBAC.md](RBAC.md) | Доступ к вкладкам по группам Keycloak | Права, авторизация, «почему я local» |
| [AUTH.md](AUTH.md) | Настройка Keycloak, oauth2-proxy и внешнего nginx | Подключение входа, выкат |
| [STORAGE.md](STORAGE.md) | Postgres и git-хранилище, таблицы, как добавить поле | Любая работа с данными |

| [LOGGING.md](LOGGING.md) | Логи приложения и nginx, как добавлять события | Диагностика и новый код |

## Карта репозитория

```
backend/                FastAPI, Python 3.9-совместимый код
  main.py               точка входа; модули подключаются одной строкой
  access.py             RBAC уровня приложения, /access/me и /access/debug
  logging_setup.py      NDJSON-логи в stdout
  share.py              короткие ссылки на вид: POST /share, GET /s/<id>
  modules/<имя>/        один модуль = один роутер
  tests/                pytest
frontend/               Vue 3 + Vite
  src/App.vue           каркас: рельс модулей, тема, короткая ссылка
  src/modules/registry.js  реестр модулей — сюда добавляется новая вкладка
  src/modules/<имя>/    один модуль = одна вкладка
  src/shared/           общее: тема, http-клиент, время, состояние в URL
  nginx.conf            прод-прокси перед статикой
docs/                   эта документация
```

Полный список переменных окружения с примерами — в
[`.env.example`](../.env.example).
